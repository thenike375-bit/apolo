# PostFactum project export

This archive contains the project source, local images and asset pointers, configuration, dependency lockfile, tests, documentation, and database migrations.

## Run locally
1. Extract the ZIP.
2. Install Bun (https://bun.sh).
3. Open a terminal in the PostFactum folder and run `bun install`.
4. Configure your local environment and connected services securely.
5. Run `bun run dev` and open the address printed in the terminal.

## Not included
- Private keys and environment files.
- Installed dependencies and generated build output (recreated by installing/building).
- Git history and internal workspace metadata.
- Online database records, user accounts, uploaded recordings, and generated film footage stored in Cloud. These are not local source files.

Asset pointer files reference online media; this archive is not a fully offline copy. Connected AI, voice, storage, authentication, and background workflows still require their configured services and access.
